Current Projects

  • Creating a toolchain/workflow for 3D vertex animations created in Blender, played back in Godot
    What grew from a fascination with applying unusual animation techniques in game jam projects, has evolved into a general-purpose vertex animation export/playback tool. It works by exporting an animation in Blender to an image and then creating a method to playback the animation in Godot. The tool addresses limitations I found with other scripts and focuses on some features that I wanted for my own game projects. These are summarized as follows
    • Support for complex meshes
      • The tool can opt to only animate a subset of vertices
      • Meshes with many materials/surfaces are supported
    • Integration with existing/complex animations
      • The playback system blends traditional skeleton/armature-based animations with vertex animations
      • A system for coordinating animations across many objects (e.g. cutscenes) is included which supports any number of embedded vertex animations
  • co-Founding a Libre Internet Club at University of Alberta
    Several other interested students and I are developing programming and securing funding to establish a community centred around open source, the fediverse, the indie web, and other related technologies. We hope to bring students at the University of Alberta together under the flag of "an internet that isn't controlled by corporations" to build, learn how to build cool shit and to build cool shit.
  • Improving well-supported semantics for description logic programs
    Much of my academic focus is concerned with the issue in the semantic web of combining open- and closed- world reasoning. In this line of research, we are examining description logic programs and their well-supportedness.
